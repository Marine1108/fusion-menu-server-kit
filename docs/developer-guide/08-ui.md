# 8. UI

Fusion draws all of its UI in one page. Use these functions instead of shipping your own NUI for common things: your script then matches the server's theme (owners pick colours and the logo in F10) and works with controller, keyboard and the player's key bindings.

All functions in this chapter are **client** unless marked otherwise. Functions that wait for the player (`Input`, `Confirm`, `Progress`, `Radial`) block the current thread, so call them from a thread or a command handler.

## Notifications

```lua
Fusion.Notify('Parcel delivered', 'success')                       -- client
Fusion.Notify('Delivered', 'success', 5000, 'Courier')             -- message, type, duration (ms), title
Fusion.Notify(src, 'You were paid $120', 'success')                -- server: player first
```

Types: `success`, `error`, `warning`, `info`, `primary` (theme colour, the default), `police`, `ambulance`. Default duration is 5 seconds. You may also pass a table: `Fusion.Notify({ title = 'Courier', text = 'Delivered' }, 'success')`. Events: `fusion:client:notify` (`message, type, duration, title`). `QBCore.Functions.Notify` and `QBCore:Notify` show the same notification.

## Menus

Data-driven panel menus. You return a description; Fusion draws it, handles input and calls you back.

```lua
Fusion.Menu.Register('courier:main', {
    build = function(ctx)
        return {
            title = 'Courier', subtitle = 'Depot',
            items = {
                { id = 'start', type = 'button', label = 'Start a route', icon = 'package', description = 'Pick up 5 parcels' },
                { id = 'vehicle', type = 'list', label = 'Van', options = { 'Boxville', 'Speedo' }, value = 1 },
                { id = 'loud', type = 'checkbox', label = 'Radio on', value = true },
                { id = 'tip', type = 'slider', label = 'Tip jar', min = 0, max = 100, step = 5, value = 20 },
                { type = 'separator', label = 'Info' },
                { id = 'stats', type = 'submenu', label = 'My stats', icon = 'star', menu = 'courier:stats' },
                { type = 'info', label = 'Parcels today', right = tostring(ctx.count or 0) },
            },
        }
    end,
    onSelect = function(item, ctx) if item.id == 'start' then TriggerServerEvent('courier:start') end end,
    onChange = function(item, ctx) print(item.id, item.value) end,   -- checkbox / list / slider / input / color
    onClose = function(ctx) end,
})

Fusion.Menu.Open('courier:main', { count = 3 })   -- ctx is passed to build and every callback
```

| Item field | Meaning |
|---|---|
| `id` | your identifier (comes back in callbacks) |
| `type` | `button` (default), `submenu`, `checkbox`, `list`, `slider`, `input`, `color`, `separator`, `info` |
| `label`, `description`, `icon`, `image`, `right` (text on the right), `badge` | display |
| `value`, `options`, `min`, `max`, `step` | for checkbox / list / slider / input / color |
| `menu`, `ctx`, `owner` | submenu: the menu id to open, its context, and the resource that registered it (default: yours) |
| `data` | anything; comes back in callbacks |
| `disabled`, `confirm` (ask "are you sure?"), `closeOnSelect` | behaviour |

The menu object may also have `layout = 'grid'` for picture tiles. `Fusion.Menu.Refresh()` rebuilds the open menu (call it after data changes), `Fusion.Menu.Back()`, `Fusion.Menu.Close()`, `Fusion.Menu.IsOpen()`.

### Adding your script to the main menu (M)

```lua
Fusion.Menu.AddRootEntry({
    id = 'courier', label = 'Courier', icon = 'package', description = 'Deliveries',
    menu = 'courier:main',      -- open this menu… or event = 'courier:client:open' to fire an event instead
    perm = 'courier.use',       -- only shown with this permission (optional)
    module = 'courier',         -- hidden while your settings page's 'enabled' toggle is off (optional)
    order = 60,                 -- position (default 50)
    condition = function() return Fusion.GetPlayerData().job.name == 'courier' end,   -- optional
})
```

The entry disappears automatically when your resource stops.

## Input dialog

```lua
local result = Fusion.Input({
    title = 'Send a parcel', submit = 'Send',
    fields = {
        { name = 'to', label = 'Recipient phone', type = 'text', required = true, placeholder = '555…' },
        { name = 'weight', label = 'Weight (kg)', type = 'number', min = 1, max = 30, default = 1 },
        { name = 'speed', label = 'Speed', type = 'select', options = { { value = 'std', label = 'Standard' }, { value = 'exp', label = 'Express' } } },
        { name = 'fragile', label = 'Fragile', type = 'checkbox' },
        { name = 'note', label = 'Note', type = 'textarea' },
    },
})
if not result then return end                 -- cancelled
print(result.to, tonumber(result.weight), result.speed, result.fragile)
```

Field types: `text`, `number`, `password`, `color`, `date`, `select`, `radio`, `checkbox`, `textarea`. Fields can have `label`, `default`, `placeholder`, `description`, `required`, `min`, `max`, `options`. Always validate the values again on the server.

`exports['qb-input']:ShowInput(...)` (QBCore format) is answered by the same dialog.

## Confirm

```lua
if Fusion.Confirm('Quit the route?', 'Undelivered parcels are lost.') then … end   -- true / false
```

## Progress bar

```lua
local finished = Fusion.Progress({
    label = 'Scanning parcel', duration = 3500, canCancel = true,
    anim = { dict = 'anim@heists@prison_heiststation@cop_reactions', clip = 'cop_b_idle', flag = 49 },   -- or scenario = 'PROP_HUMAN_BUM_BIN'
    prop = { model = 'prop_cs_package_01', bone = 28422, pos = vector3(0.0, 0.0, 0.0), rot = vector3(0.0, 0.0, 0.0) },
    disable = { move = true, car = true, combat = true, mouse = false },
})
if not finished then return end   -- cancelled (X by default) or another progress bar was running
```

`exports['fusion-core']:IsProgressActive()`. `exports['progressbar']:Progress(...)` and `QBCore.Functions.Progressbar(...)` use the same bar.

## Text UI (prompts)

```lua
Fusion.TextUI.Show(('[%s] Pick up parcel'):format(Fusion.Key.Label('interact')), 'left')   -- 'left' (default), 'right' or 'top'
Fusion.TextUI.Hide()
```

Text in `[brackets]` is drawn as a key. Always build the label with `Fusion.Key.Label` (below), because players can rebind keys. `exports['qb-core']:DrawText` / `HideText` work too.

## Radial picker

```lua
local choice = Fusion.Radial('Parcel', {
    { label = 'Deliver', icon = 'check', value = 'deliver' },
    { label = 'Return', icon = 'refresh', value = 'return', description = 'Back to the depot' },
})
```

Returns the chosen `value`, or `nil`.

## Context menu (qb-menu style)

```lua
exports['fusion-core']:OpenContext({
    { header = 'Courier', isMenuHeader = true },
    { header = 'Start route', txt = 'Five parcels', icon = 'package', params = { event = 'courier:client:start' } },
    { header = 'Pay out', txt = '$120', params = { isServer = true, event = 'courier:server:payout', args = { route = 3 } } },
}, nil)   -- second argument: optional function(item, index) instead of params
exports['fusion-core']:CloseContext()
```

`params` supports `event` (client event), `isServer`, `isCommand`, `isQBCommand`, `isAction` (`event` is a function), and `args`. `exports['qb-menu']:openMenu(...)` uses the same menu.

## HUD

`Fusion.SetHud('custom', 'Route 3/5')` shows a small status chip on the HUD (`nil` removes it). Other HUD keys are used by Fusion itself.

### Speedometer and windshield HUD

The speedometer style (classic, dial, digital, sport, minimal) and the first-person windshield HUD are chosen by the
owner (Settings › Interface › HUD) and each player (M › Misc Settings). Your script doesn't need to do anything;
if you draw your own speedometer, tell owners to switch Fusion's off with *Vehicle HUD*.

## Streamer mode, video mode and recording

Players can hide things from their own screen (M › Streaming & Video). If your script shows something a streamer
would hide, check before drawing it (client):

```lua
if not exports['fusion-core']:IsStreamerHidden('names') then DrawText3D(...) end
```

| Key | Hidden thing |
|---|---|
| `chat` | the chat box |
| `names` | names / IDs above players |
| `playerlist` | names / IDs in menus and lists |
| `myid` | the player's own server ID |
| `money` | cash, bank, money popups |
| `job` | the player's job |
| `location` | street, postal, compass, coordinates |
| `minimap` | the minimap |
| `phone` | phone numbers |
| `radio` | voice / radio channel |
| `notifications` | notifications |

`IsStreamerHidden` is also true for everything during **video mode** (a clean screen for filming), so one check
covers both. Other client exports: `IsStreamerMode()`, `IsVideoMode()`, `IsRecording()` (Fusion Recorder or a
Rockstar Editor recording). The client event `fusion:client:privacyChanged(hidden, videoMode)` fires whenever
any of it changes (`hidden` is a table of the keys above that are hidden right now).

The Fusion Recorder records only the game picture, never NUI, so your NUI is never in a player's clip. Things
you draw with natives (`DrawText`, `DrawRect`, markers) are in the game picture, so they are recorded.

## Key bindings

Fusion's keys are FiveM key bindings, so players rebind them in **Settings › Key Bindings › FiveM**. Use them instead of hard-coded control IDs:

| Name | Default | Meaning |
|---|---|---|
| `interact` | E | the main `[E]` interaction |
| `interact2` | G | a second interaction |
| `cancel` | X | cancel the current action |
| `target_select` | left mouse | pick a third-eye option |

```lua
if Fusion.Key.Pressed('interact') then … end   -- this frame (call every frame inside your loop)
if Fusion.Key.Held('interact') then … end
local label = Fusion.Key.Label('interact')     -- 'E', or whatever the player chose
```

For your own keys, use `RegisterKeyMapping` too, so players can rebind them.

Fusion's own streaming keys are unbound by default (players pick them): `streamer`, `+fusion_peek` (hold to show
everything), `videomode`, `freecam`, `record`.

## Third eye (targeting)

`fusion-target` implements the **qb-target API**, and calls to `exports['qb-target']:*` are answered by it, so existing code works:

```lua
exports['qb-target']:AddCircleZone('courier_depot', vector3(78.7, 111.9, 81.2), 1.5, { name = 'courier_depot', useZ = true }, {
    options = {
        { icon = 'fas fa-box', label = 'Start a route', job = 'courier', action = function(entity) TriggerEvent('courier:client:start') end },
        { icon = 'fas fa-box', label = 'Collect pay', job = { courier = 1 }, event = 'courier:server:payout', type = 'server' },
    },
    distance = 2.0,
})
```

Functions: `AddCircleZone`, `AddBoxZone`, `AddPolyZone`, `AddComboZone`, `AddEntityZone`, `RemoveZone`, `UpdateZoneData`, `AddTargetEntity`, `RemoveTargetEntity`, `AddTargetModel`, `RemoveTargetModel`, `AddTargetBone`, `RemoveTargetBone`, `AddGlobalPed` / `Vehicle` / `Object` / `Player` (and `AddGlobalType`), `RemoveGlobal*`, `SpawnPed`, `RemoveSpawnedPed`, `AllowTargeting`, `DisableTarget`, `IsTargetActive`, `RaycastCamera`, `Get*Data`.

Option filters: `job` (a name, `'all'`, a list of names, or `{ jobname = minimumGrade }`), `excludejob`, `gang`, `citizenid`, `item`, `canInteract = function(entity, distance, option) return true end`. Actions: `action` (function), `event` with `type = 'client'` (default) / `'server'` / `'command'` / `'qbcommand'`.

## Your own NUI

If you need a full custom interface, ship your own NUI page as usual. Fusion doesn't interfere, but call `SetNuiFocus` yourself and close your UI on `fusion:client:playerUnloaded`.
